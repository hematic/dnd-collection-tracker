      Help & About

      Quick guides for browsing and managing your collection. Use the ? buttons beside a section to jump to its help.

      Browsing the collection

      Switch between Shelves, Grid, and Table in the top bar. Select a cover to open its linked PDF, or open the book details when no PDF is linked. Click the title beneath a cover, use Shift-click, or select a table row to open details directly.

      Filters and sorting

      Use the sidebar to sort and filter by release, ownership, year, edition, book type, setting, or publisher. Under Setting, select one or more names or “No setting set” to find books without a setting. Under Publisher, select one or more names or “No publisher set” to find releases with a blank publisher. Publisher is also available in the Sort menu. “Has No Linked PDF” finds books without a PDF linked to any release; when showing every release separately, it finds individual releases without links. The search field matches titles, product codes, ISBNs, settings, and publishers. Reset all clears the filters. Your current collection view is saved in the URL, so filtered views can be bookmarked.

      Ownership and releases

      Ownership is tracked per release (printing). Mark physical and PDF ownership separately in a book's details. By default, a book appears once using its shelf-default release; enable “Show every release separately” to see all printings.

      Exporting your inventory

      Open Export in the sidebar and choose “Current filtered view” to download just the matching collection entries, using the active filters, sort order, and release options. With “Show every release separately” enabled, each matching release gets its own CSV row. The separate export Edition control is disabled for this option because the collection's edition filters are used instead. You can also export the full inventory, physically owned books, or books not physically owned, optionally choosing one edition.

      Searching PDF contents

      PDF Search is separate from the collection search. Results update when you pause typing or press Enter. Choose whether all words, any word, or an exact phrase must match. Search terms also match word endings (for example, “troll” matches “trolls”). Toggle editions to show or hide their results. Matches are grouped by book printing, sorted by title, and listed in PDF page order. The CSV includes every matching PDF page for the selected editions, even if you haven't loaded it on screen.

      Indexing PDFs

      PDF text must be indexed before it can be searched. Editors start indexing from the PDF Search page; it runs in the separate Docker OCR worker and does not start automatically. Pause takes effect after the current page; resume continues queued work. Scanned pages are OCRed locally, and original PDFs are unchanged. When OCR counts are recorded, they appear on each printing in the book details drawer.

      Importing PDFs from your library

      Editors can scan the configured library and link PDFs in batches. Check the suggested printing and first-page preview before linking. Choose a printing for uncertain matches, or ignore files you don't want to link. Rescanning keeps your saved decisions for files that are still present. Import does not replace existing links or start PDF indexing.

      Editing and access

      Access depends on the deployment configuration. In the Docker deployment, admins can add and update books, releases, covers, and ownership; other users can browse and search. Use the book details drawer to edit a book or one of its releases.
